# WSP 2026年度モンゴル実験

和歌山大学宇宙開発プロジェクト（WSP）が、2026年度のモンゴル実験で使う電装とプログラムを置くリポジトリです。回路・基板（KiCad）と、マイコンやPC側のプログラムを同じ場所で管理します。

リモート: https://github.com/wsp-space/evt_26mongolia

## 管理するもの

| 分野 | 置くもの | 主なファイル |
| :--- | :--- | :--- |
| ハードウェア | 回路図、基板パターン | `*.kicad_pro`, `*.kicad_sch`, `*.kicad_pcb` |
| ソフトウェア | マイコンおよびPC側のプログラム | ソース一式 |

繰り返し使うシンボルとフットプリントは [kicad_libraries](https://github.com/wsp-space/kicad_libraries) にあります。

## ディレクトリ

設計データはこれから追加します。追加するときは次のように分けます。

- `hardware/` : KiCad プロジェクト（回路図・PCB）
- `software/` : マイコン、PC側のプログラム

## 開発環境

- 基板設計: [KiCad](https://www.kicad.org/)
- 共通部品: [kicad_libraries](https://github.com/wsp-space/kicad_libraries) をクローンし、KiCad のシンボルライブラリ／フットプリントライブラリに追加する。ニックネームは `WSP_` で始める

## Git に含めないファイル

`.gitignore` は KiCad の作業ファイルのうち、再生成できるものと個人設定を除外しています。コミットされない主なものは次のとおりです。

| 対象 | パターンの例 | 理由 |
| :--- | :--- | :--- |
| バックアップ | `*.kicad_sch-bak`, `*.kicad_pcb-bak`, `*-backups` | 自動保存・退避 |
| ネットリスト | `*.net` | 回路図から書き出せる |
| 自動配線の受け渡し | `*.dsn`, `*.ses` | 外部ルータ用 |
| BOM | `*.xml`, `*.csv` | 回路図から書き出せる |
| ローカル履歴 | `.history` | KiCad 9 以降のローカル履歴 |
| 個人設定 | `*.kicad_prl` | マシンごとの表示設定 |

`*.xml` と `*.csv` は拡張子単位で除外しています。共有したい書き出しがある場合は、ファイル名で書き出しだと分かるようにしたうえで、除外規則の見直しを Issue で相談してください。

## 📝 Issue・コミットメッセージの命名規則

当プロジェクトでは、Issueのタイトルおよびコミットメッセージに [Conventional Commits](https://www.conventionalcommits.org/) 風のプレフィックスルールを採用しています。
ハードウェア（KiCad）とソフトウェア（プログラム）が混在するため、スコープ（分野）を明記してください。

### フォーマット
`種類(スコープ): タイトル`
（例: `feat(sch): モータードライバ回路の追加`）

新規Issueは、GitHubの作成画面にあるテンプレートから作ってください。種類ごとにテンプレートがあり、タイトル欄は `種類(スコープ): ` が入った状態で開きます。括弧内の「スコープ」は、テンプレートで選んだ分野（`hw` / `sch` / `pcb` / `sw` / `sys`）に置き換えてください。

### 1. 種類 (Type)
| プレフィックス | 意味 | 用途の例 |
| :--- | :--- | :--- |
| `feat` | 新機能・新規追加 | 新しい回路の追加、新機能のプログラム実装 |
| `fix` | 修正・バグ対応 | 回路のミス修正、プログラムのバグ修正 |
| `refactor` | 整理・リファクタ | パターン配線の引き直し、コードの整理（動作は変えない） |
| `docs` | ドキュメント | READMEの更新、仕様書の追加 |
| `chore` | 雑務・その他 | ライブラリの更新、CI/CDの設定、ビルドのみ |

### 2. スコープ (Scope)
作業した分野をカッコ内に記載します。

| スコープ | 対象分野 | 補足 |
| :--- | :--- | :--- |
| `hw` | ハードウェア全般 | 分類に迷った基板・回路関連 |
| `sch` | 回路図 (Schematic) | KiCadの回路図エディタでの作業 |
| `pcb` | パターン設計 (PCB) | KiCadのPCBエディタでの作業 |
| `sw` | ソフトウェア全般 | マイコンやPC側のプログラム |
| `sys` | システム全体 | HWとSWの両方にまたがる変更・連携部分 |

### 記述例
* `feat(sw): センサーのI2C通信処理を実装`
* `fix(pcb): 3.3Vラインの配線幅が細すぎる問題を修正`
* `refactor(sch): 抵抗のシンボルを統一`
